## 🐍 Características do Python

- Linguagem de programação de alto nível, interpretada e de tipagem dinâmica.
- Suporta múltiplos paradigmas de programação: orientada a objetos, funcional e imperativa.
- Sintaxe simples e legível, facilitando a escrita e manutenção do código.

## 🔧 Antes de instalar

Verifique se o Python já está instalado:

```bash
python --version
```

Exemplo de saída:

```text
Python 3.14.7
```

---

## 📥 Instalar o Python

1. Acesse [python.org/downloads](https://www.python.org/downloads/).
2. Clique em **Download Python** para baixar a versão mais recente.
3. Para Windows, baixe o instalador disponível no site.
4. Execute o instalador e siga as instruções.
5. Confirme a instalação:

```bash
python --version
```

---

## 👋 Olá Mundo em Python

1. Crie uma pasta para o projeto e abra no VS Code.
2. Crie o arquivo `hello.py`:

```python
print("Olá, mundo!")
```

3. Execute no terminal:

```bash
py hello.py
```
